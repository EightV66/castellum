# CASTELLUM — The Last Kingdom

最后的王国 · 霜翼群峰 · 2.0

一个可以从山下绕到翼尖背面的实时三维世界。在西侧山口能看见冰翼的完整轮廓，在东侧能沿九折王道辨认王冠主堡、山腰的戍堡和霆冠上城。

## 打开王国

可以直接在浏览器中体验以下机位。

- [电影巡游](https://eightv66.github.io/castellum/) 从整个山系的远景进入，经过两座近景哨塔，最后停在主堡前。
- [西山口 · 冰翼全景](https://eightv66.github.io/castellum/?time=morning&ui=0#wing) 适合比较翼展和山顶建筑的尺度。
- [东坡 · 九折王道](https://eightv66.github.io/castellum/?ui=0#road) 可以同时看到路的折角、岩嘴的承重砌体和三座山城。
- [九折王道 · 雷暴](https://eightv66.github.io/castellum/?weather=storm&ui=0#road) 能看到闪电击中上城的北塔尖端。

以上三个地标直达链接默认收起界面。按 **H** 或 **Esc** 恢复。鼠标左键拖动环视、右键平移、滚轮缩放。触屏上单指环视、双指平移或缩放，小屏通过王国地图选地点。**1** 返回主堡，**C** 重启巡游，**M** 切换声场。

下载或克隆仓库后，在装有 Node.js 的 Windows 电脑上双击 **启动城堡.cmd**，即可离线体验。启动器会从本地构建或随仓库提供的 `docs` 目录提供网页，浏览器自动打开 [本地入口](http://127.0.0.1:4173/)。按 Ctrl+C 可停止自己启动的服务。

## 建筑与地形

- 山翼由一条岩心、十一道舒展的岩层和两道插入山体的基岩组成。每一层有不同的起点、掠角、褶皱、厚度和断口。石材、冰缝和积雪沿表面方向变化。
- 峰体承托三座功能不同的城堡。王冠主堡借鉴哥特建筑语汇，有透空石肋双塔、三重门廊、石制玫瑰窗棂、彩玻、飞扶壁和放射状后殿。霆冠上城沿不规则山肩砌筑，有独立的殿堂、廊窗和北塔引雷尖顶。
- 八组有方向的刃脊分出窄脊线和不对称岩面。山道以较长的直段越过岩坡，在突出崖面的短折角转向。外侧设尖角石台、收分的挡墙和断续石栏。道路开挖、放坡和地形网格共用路线数据。
- 冰碛、三重远山、村庄、针叶林、冰瀑、峡谷雾层、云幕和巡飞的鸟群构成山地环境。两幅本地纹理提供云层和岩石的表面细节。城堡、山翼、山路及山脉均可从不同方向观察。

## 探索与环境控制

左侧导航和王国地图提供十二个独立机位。地点有中英文名称、中文地志和返回入口。可点选模型或地标，随时切换电影巡游和自由视角。

世界之息面板提供五个时段、六种天气、三档画质，以及泛光、环境遮蔽、镜头边缘柔焦控制。云光、积雾和窗户照明平滑变化。降雪和斜雨跟随观察位置，雷暴会照亮北塔及周边岩壁。点击声音后，浏览器通过 Web Audio 合成冰川低鸣、山风、雨、雷、暮钟和持续低声部，各声部可独立调节。

## 开发

使用 Node.js 22.12 或更高版本，或 20.19 及以上的 20.x。生产版也可以直接用 `node server.mjs` 启动。编辑源码时，在本目录执行以下命令。

```powershell
npm ci
npm run dev
```

开发入口是 [本地开发服务器](http://127.0.0.1:5173/)。`npm test` 执行场景几何和相机回归检查，`npm run build` 更新 `dist`。Three.js、纹理和音频均在本地运行。

更新线上版本时，运行 `npm test` 和 `npm run build:pages`，将源码与生成的 `docs/` 一起提交到 `main` 并推送。GitHub Pages 从该目录发布。

## 运行成本与验证边界

| 画质 | 像素比上限 | 阴影贴图 | 默认后期 |
| --- | --- | --- | --- |
| 流畅 | 1.0 | 关闭 | 色调映射、FXAA |
| 高画质 | 1.35 | 2048² | 泛光、色调映射、FXAA |
| 极致 | 1.75 | 4096² | SSAO、泛光、色调映射、FXAA |

静态建筑按材质合批。830 棵针叶树使用实例化，树冠按观察距离切换两级几何。场景对阴影重绘限频，翼山碰撞先查包围盒，地面碰撞直接采样渲染网格的三角形。雨线和雪花分别限制为 1,400 条和 3,800 个，隐藏页面时暂停动画提交。

探索范围为建筑外部和群峰地形。网页版需要 WebGL 2 和硬件加速。实物打印与装配未验证。不同显卡与实体手机的帧率需要在目标设备测量。当前验收数据与本轮浏览器截图见 [霜翼群峰验收记录](artifacts/11-18_霜翼群峰验收.md)，素材说明见 [来源与许可](ASSETS.md)。
